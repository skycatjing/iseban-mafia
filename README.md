# 이세밴 마피아 사회자 도구

이세계아이돌 팬밴드 마피아 게임 이벤트용 사회자 보조 도구입니다.
직업 무작위 배정과 특수효과 확률 판정을 자동으로 처리하고, 밴드 채팅에 바로 붙여넣을 수 있는 통보 문구를 만들어 줍니다.

**👉 [바로 사용하기](https://skycatjing.github.io/iseban-mafia/)**

설치할 것이 없습니다. 링크를 열거나 `index.html`을 브라우저로 열면 바로 실행되고, 인터넷 연결 없이도 동작합니다.
입력한 내용과 배정 결과는 브라우저에 저장되어 새로고침해도 유지됩니다.

## 화면 구성

### 설정
- 참여자 닉네임 입력 (줄바꿈 또는 쉼표 구분, 중복 자동 제거)
- 마피아 / 시민 / 중립 인원을 각각 지정, 또는 자동 분배
- 직업별 3단 설정 — **자동**(랜덤 후보) / **고정**(반드시 포함) / **제외**(안 나옴)
- **특수직업 인원** — 마피아 팀 · 시민 팀에 특수직업을 각각 몇 명 넣을지 지정
  - 나머지 자리는 일반 `마피아` · `시민`으로 채워집니다 (예: 시민 7명 중 특수 3명 → 특수 3 + 일반 시민 4)
  - `0`으로 두면 그 팀은 전원 일반 직업이 됩니다
  - 팀 인원보다 크게 넣거나 쓸 수 있는 직업 종류가 모자라면, 설정 화면에 미리 표시되고 배정 시에도 안내됩니다
  - 중립은 일반 직업이 없어서 항상 전원 특수직업입니다

#### 직업 조합 규칙
**기자와 탐정은 절대 함께 나오지 않습니다.** 둘 중 하나만 등장합니다.

- **청부업자가 배정되면** → 탐정 포함 + 기자 제외
- **청부업자가 없으면** → 기자 포함 + 탐정 제외
- 어떤 직업을 청부업자 / 기자 / 탐정으로 볼지 화면에서 직접 지정할 수 있습니다.
  (기본값: 히트맨 비챤 / 이세계뉴스 기자 / 크라임왁 고세구)
- 이 규칙은 개별 고정 · 제외 설정보다 우선 적용되며, 뒤집힌 경우 배정 시 안내가 뜹니다.

### 배정 결과
- 사회자 확인용 전체 명단
- 마피아 팀 단톡용 문구 (팀원 명단 포함)

### 통보 문구
- 참여자를 고르면 **그 사람에게 보낼 문구만** 표시되고 버튼 하나로 복사됩니다
- 복사하면 보낸 표시(✓)가 남고 자동으로 다음 사람으로 넘어갑니다
- 마피아 직업에는 팀원 명단이 자동으로 붙습니다
- 전체를 한 번에 복사할 수도 있습니다

### 진행
- **진행 시점 (밤 / 낮)** — 배정 직후가 `1번째 밤`, **이전 / 다음** 버튼으로 밤 → 낮 → 다음 밤 순으로 전환
  - 모든 판정 기록에 몇 번째 밤·낮이었는지가 함께 남습니다
  - 잘못 넘겼으면 **이전**으로 되돌리면 됩니다
- 생존자 클릭으로 사망 / 부활 전환
- **이번 판에 배정된 직업의 판정만** 버튼으로 표시
  - 뚤기 — 사망 위기 생존 50% (2회 소진 시 자동 비활성화, 남은 횟수 자동 표기). 버튼은 하나이고, **지금이 밤이면 마피아 습격 멘트 · 낮이면 투표 처형 멘트**가 자동으로 나옵니다
  - 성녀 아이네 — 사망자 부활 33% / 생존자 구제 33%
  - 행동대장 릴파 — 추가 사살 33%
  - 만취백송도 — 생존자 중 무작위 3명 추첨
- 판정에 성공하면 해당 직업의 능력 성공 멘트가 함께 표시됩니다
- 수동 확률 굴림, 무작위 추첨, 판정 기록 로그 제공
- **초기화**
  - `판 초기화` — 배정 결과 · 생사 · 능력 사용 횟수 · 통보 체크 · 판정 기록을 지우고 1번째 밤으로 되돌립니다 (참여자 명단과 설정은 유지)
  - `전체 초기화` — 참여자 명단과 직업 설정까지 처음 상태로
  - 둘 다 접속한 모든 기기에 함께 적용되며 되돌릴 수 없습니다

### 대사집
- 승리 멘트 (시민 / 마피아 / 깨뚤 / 만취백송도 3단 / 비챤섹시교 교주)
- 능력 발동 멘트
- 전체 직업 목록

## 실시간 동기화

PC와 폰, 또는 공동 사회자끼리 **같은 진행 상태를 실시간으로 공유**합니다.
방은 **하나로 고정**이고 파이어베이스 설정도 [`index.html`](index.html)에 들어 있어서, **설정할 것도 방을 만들 것도 없습니다.**
사이트를 열면 그냥 연결됩니다.

- 배정, 밤/낮 전환, 사망 처리, 판정 기록이 접속한 모든 기기에 실시간 반영됩니다
- 새로고침해도 진행 상태가 그대로 남습니다
- 화면에 연결 상태를 따로 표시하지 않습니다. 동기화가 실패했을 때만 설정 탭 맨 위에 빨간 안내가 뜹니다

### ⚠️ 이 주소 자체가 비밀번호입니다

방이 하나뿐이라 **주소를 아는 사람은 누구나 누가 마피아인지 전부 볼 수 있습니다.**
참여자에게 절대 알려주지 마시고, 밴드 채팅이나 공개된 곳에 붙여넣지 마세요. 사회자끼리만 쓰세요.

파이어베이스 설정값(`apiKey` 등)은 브라우저에서 쓰라고 만들어진 값이라 공개되어도 무방합니다.
데이터베이스 보안 규칙은 [`database.rules.json`](database.rules.json)에 있으며, 방 목록 전체 조회와 형식이 맞지 않는 데이터를 거부합니다.

### 알아둘 점

- 동시에 두 사람이 조작하면 **나중에 반영된 쪽이 이깁니다.** 한 명이 주로 조작하는 편이 안전합니다
- 판이 끝나면 **판 초기화**로 정리하고 다음 판을 시작하세요
- 무료 한도(동시 접속 100, 월 10GB 전송)로 이 용도에는 차고 넘칩니다

## 직업 데이터

직업 능력과 통보 멘트는 아래 두 문서를 기준으로 합니다.

- [이세밴] 마피아 직업 요약
- [이세밴] 마피아 직업 통보 멘트

`박쥐`와 일반 `시민`은 통보 멘트 문서에 항목이 없어 능력 설명을 바탕으로 임시 작성했습니다.
해당 직업 데이터에는 `noMsg: true` 표시가 되어 있으니, 공식 멘트가 정해지면 교체해 주세요.

직업을 추가하거나 수정하려면 `index.html` 안의 `ROLES` 배열을 편집하면 됩니다.

```js
{id:'ddulgi', name:'뚤기', emoji:'🛡️', team:'citizen',
 desc:'모든 사망 위기 시 50% 확률로 생존 (최대 2회)',
 msg:`[시민]
당신은 "🛡️ 뚤기" 입니다.
...`,
 rolls:[{label:'사망 위기 생존 판정', p:50, limit:2,
   ok:{
     night:`... {name}님이 마피아의 습격을 극복하였습니다`,
     day:`... {name} 님이 투표의 죽음을 극복했습니다.`
   }}]},
```

| 항목 | 설명 |
| --- | --- |
| `team` | `mafia` / `citizen` / `neutral` |
| `filler` | `true`면 남는 자리를 채우는 기본 직업 (`시민`, `마피아`) |
| `msg` | 개인 통보 문구 |
| `lines` | 대사집에 실리는 능력 발동 멘트 |
| `rolls` | 확률 판정 버튼 — `p` 확률(%), `limit` 사용 횟수, `ok` 성공 시 멘트 |
| `picks` | 무작위 대상 추첨 버튼 — `n` 인원 |

`ok`에 문자열 대신 `{night, day}` 객체를 넣으면, 진행 탭의 현재 시점이 밤이냐 낮이냐에 따라
멘트가 자동으로 갈립니다. 판정 버튼은 하나로 유지되고, 대사집에는 밤·낮 두 항목으로 실립니다.

`ok` 멘트 안의 `{left}`는 남은 사용 횟수, `{name}`은 그 직업을 가진 참여자 닉네임으로 자동 치환됩니다.
(대사집에서는 `{name}`이 `(닉네임)`으로 표시됩니다.)
