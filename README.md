# [이세밴] 마피아 사회자 도구

이세계아이돌 팬밴드 마피아 게임 이벤트용 사회자 보조 도구입니다.
직업 무작위 배정과 특수효과 확률 판정을 자동으로 처리하고, 밴드 채팅에 바로 붙여넣을 수 있는 문구를 만들어 줍니다.

**👉 [바로 사용하기](https://GITHUB_ID.github.io/iseban-mafia/)**

> 위 주소의 `GITHUB_ID` 부분을 본인 깃허브 아이디로 바꿔주세요.

## 기능

### ① 설정 & 배정
- 참여자 닉네임 입력 (줄바꿈 또는 쉼표 구분, 중복 자동 제거)
- 마피아 팀 / 시민 팀 / 중립 인원을 각각 자유롭게 지정
- 직업별 3단 설정 — **자동**(랜덤 후보) / **고정**(반드시 포함) / **제외**(안 나옴)
- 남는 자리 처리 선택
  - 켜면 일반 `시민` · `마피아`로 채움
  - 끄면 전부 특수직업으로 채움 (직업 종류가 부족하면 경고와 함께 자동 보충)

### 직업 조합 규칙
- **청부업자가 배정되면** → 기자 제외 + 탐정 포함
- **청부업자가 없으면** → 기자 + 탐정 모두 포함
- 어떤 직업을 청부업자 / 기자 / 탐정으로 볼지는 화면에서 직접 지정할 수 있습니다.
  (기본값: 히트맨 비챤 / 이세계뉴스 기자 / 크라임왁 고세구)
- 이 규칙은 개별 '제외' 설정보다 우선 적용됩니다.

### ② 배정 결과
복사 버튼 한 번으로 밴드 채팅에 붙여넣을 수 있습니다.
- 사회자용 전체 명단
- 개인 DM용 문구 (진영 · 직업 · 능력 · 승리조건)
- 마피아 팀 단톡용 문구 (팀원 명단 포함)
- 전체 공지용 문구 (누가 무엇인지는 비공개, 구성만 공개)

### ③ 진행 (확률 굴림)
- 생존자 클릭으로 사망 / 부활 전환
- **이번 판에 실제로 배정된 직업의 확률만** 버튼으로 자동 생성
  - 뚤기 — 사망 위기 생존 50% (2회 소진 시 버튼 자동 비활성화)
  - 성녀 아이네 — 사망자 부활 33% / 생존자 구제 33%
  - 행동대장 릴파 — 추가 사살 33%
  - 만취백송도 — 생존자 중 무작위 3명 추첨 (본인 포함)
- 수동 확률 굴림 및 무작위 대상 추첨
- 모든 판정 기록이 로그로 남고 복사 가능

### ④ 직업 사전
전체 직업 목록과 능력, 자동 판정 확률을 한눈에 볼 수 있습니다.

## 사용 방법

별도 설치가 필요 없습니다. 위 링크를 열거나 `index.html`을 브라우저로 열면 바로 실행됩니다.
인터넷 연결 없이도 동작하며, 입력한 내용은 브라우저에 자동 저장되어 새로고침해도 유지됩니다.

## 직업 데이터

직업 목록과 능력 설명은 **[이세밴] 마피아 직업 요약** 문서를 기준으로 합니다.
직업을 추가하거나 수정하려면 `index.html` 안의 `ROLES` 배열을 편집하면 됩니다.

```js
{id:'ddulgi', name:'뚤기', team:'citizen',
 desc:'모든 사망 위기 시 50% 확률로 생존 (최대 2회)',
 rolls:[{label:'사망 위기 생존 판정', p:50, limit:2}]},
```

- `team` — `mafia` / `citizen` / `neutral`
- `filler: true` — 남는 자리를 채우는 기본 직업 (`시민`, `마피아`)
- `rolls` — 확률 판정 버튼 (`p` 확률 %, `limit` 사용 횟수 제한)
- `picks` — 무작위 대상 추첨 버튼 (`n` 인원)
