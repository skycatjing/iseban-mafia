# 이세밴 마피아 사회자 도구

이세계아이돌 팬밴드 마피아 게임 이벤트용 사회자 보조 도구입니다.
직업 무작위 배정과 특수효과 확률 판정을 자동으로 처리하고, 밴드 채팅에 바로 붙여넣을 수 있는 통보 문구를 만들어 줍니다.

**👉 [바로 사용하기](https://skycatjing.github.io/iseban-mafia/)**

설치할 것이 없습니다. 링크를 열거나 `index.html`을 브라우저로 열면 바로 실행되고, 인터넷 연결 없이도 동작합니다.
입력한 내용과 배정 결과는 브라우저에 저장되어 새로고침해도 유지됩니다.

## 화면 구성

### 설정
- 참여자 닉네임 입력 (줄바꿈 또는 쉼표 구분, 중복 자동 제거)
- 마피아 / 시민 / 중립 인원을 각각 지정, 또는 자동 분배
- 직업별 3단 설정 — **자동**(랜덤 후보) / **고정**(반드시 포함) / **제외**(안 나옴)
- 남는 자리 처리
  - 켜면 일반 `시민` · `마피아`로 채움
  - 끄면 전부 특수직업으로 채움 (직업 종류가 부족하면 안내와 함께 자동 보충)

#### 직업 조합 규칙
- **청부업자가 배정되면** → 기자 제외 + 탐정 포함
- **청부업자가 없으면** → 기자 + 탐정 모두 포함
- 어떤 직업을 청부업자 / 기자 / 탐정으로 볼지 화면에서 직접 지정할 수 있습니다.
  (기본값: 히트맨 비챤 / 이세계뉴스 기자 / 크라임왁 고세구)
- 이 규칙은 개별 제외 설정보다 우선 적용됩니다.

### 배정 결과
- 사회자 확인용 전체 명단
- 마피아 팀 단톡용 문구 (팀원 명단 포함)
- 전체 공지용 문구 (누가 무엇인지는 비공개, 구성만 공개)

### 통보 문구
- 참여자를 고르면 **그 사람에게 보낼 문구만** 표시되고 버튼 하나로 복사됩니다
- 복사하면 보낸 표시(✓)가 남고 자동으로 다음 사람으로 넘어갑니다
- 마피아 직업에는 팀원 명단이 자동으로 붙습니다
- 전체를 한 번에 복사할 수도 있습니다

### 진행
- 생존자 클릭으로 사망 / 부활 전환
- **이번 판에 배정된 직업의 판정만** 버튼으로 표시
  - 뚤기 — 사망 위기 생존 50% (2회 소진 시 자동 비활성화, 남은 횟수 자동 표기)
  - 성녀 아이네 — 사망자 부활 33% / 생존자 구제 33%
  - 행동대장 릴파 — 추가 사살 33%
  - 만취백송도 — 생존자 중 무작위 3명 추첨
- 판정에 성공하면 해당 직업의 능력 성공 멘트가 함께 표시됩니다
- 수동 확률 굴림, 무작위 추첨, 판정 기록 로그 제공

### 대사집
- 승리 멘트 (시민 / 마피아 / 깨뚤 / 만취백송도 3단 / 비챤섹시교 교주)
- 능력 발동 멘트
- 전체 직업 목록

## 직업 데이터

직업 능력과 통보 멘트는 아래 두 문서를 기준으로 합니다.

- [이세밴] 마피아 직업 요약
- [이세밴] 마피아 직업 통보 멘트

`박쥐`와 일반 `시민`은 통보 멘트 문서에 항목이 없어 능력 설명을 바탕으로 임시 작성했습니다.
해당 직업 데이터에는 `noMsg: true` 표시가 되어 있으니, 공식 멘트가 정해지면 교체해 주세요.

직업을 추가하거나 수정하려면 `index.html` 안의 `ROLES` 배열을 편집하면 됩니다.

```js
{id:'ddulgi', name:'뚤기', emoji:'🛡️', team:'citizen',
 desc:'모든 사망 위기 시 50% 확률로 생존 (최대 2회)',
 msg:`[시민]
당신은 "🛡️ 뚤기" 입니다.
...`,
 rolls:[{label:'사망 위기 생존 판정', p:50, limit:2,
   ok:`죽음조차 당신을 피해가는군요! ... 남은 기회는 ({left})번 입니다.`}]},
```

| 항목 | 설명 |
| --- | --- |
| `team` | `mafia` / `citizen` / `neutral` |
| `filler` | `true`면 남는 자리를 채우는 기본 직업 (`시민`, `마피아`) |
| `msg` | 개인 통보 문구 |
| `lines` | 대사집에 실리는 능력 발동 멘트 |
| `rolls` | 확률 판정 버튼 — `p` 확률(%), `limit` 사용 횟수, `ok` 성공 시 멘트 |
| `picks` | 무작위 대상 추첨 버튼 — `n` 인원 |

`ok` 멘트 안의 `{left}`는 남은 사용 횟수로 자동 치환됩니다.
